# RallyRoom
**One chat. One mission.**
Proposed repository: `rallyroom-twitch` (availability/trademark clearance unchecked).
Elevator pitch: A cooperative Twitch game where viewers scout, build and power a shared rescue mission through chat, while an OBS overlay shows everyone’s progress.

## Start
1. Open a dedicated OpenAI Codex build thread.
2. Paste CODEX_BUILD_PROMPT.md; build primarily in that thread.
3. Record the actual main build session ID and evidence in docs/CODEX_BUILD_LOG.md.

Application not started. This kit contains specifications, drafts and generated branding, not a working Twitch integration. No runtime OpenAI API key is required by the proposed design. Do not substitute Freebuff-only development for required Codex use.

Local-first persistent Node server receives authorized Twitch chat and pushes game state to an OBS browser overlay. A simulated chat mode supports tests but never substitutes for real Twitch proof. Sites hosting is not required; persistent EventSub worker hosting needs runtime verification before cloud deployment.
